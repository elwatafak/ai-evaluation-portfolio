# AI Evaluation Portfolio

A practical portfolio focused on evaluating AI-generated responses for factual accuracy, instruction following, clarity, usefulness, and Spanish (Mexico) language quality.

## About this repository

This repository contains **portfolio exercises** designed to demonstrate a structured approach to AI response evaluation. The examples are intentionally self-contained and do not contain confidential client data or proprietary evaluation material.

## Evaluation areas

- **Factual accuracy** — identifying unsupported or incorrect claims.
- **Instruction following** — checking whether a response satisfies explicit user constraints.
- **Response comparison** — selecting the stronger answer using consistent criteria.
- **Spanish (Mexico) quality** — reviewing grammar, clarity, natural phrasing, and regional appropriateness.
- **Prompt analysis** — identifying ambiguity and improving prompts without changing the user's intent.

## Evaluation framework

When reviewing an AI response, I consider:

1. **Correctness** — Are factual claims accurate and supported?
2. **Relevance** — Does the answer address the user's actual request?
3. **Instruction following** — Were all explicit constraints respected?
4. **Clarity** — Is the response understandable, concise, and well organized?
5. **Completeness** — Does it include the information needed to answer the task?
6. **Language quality** — Is the grammar and wording natural for the requested locale?
7. **Safety and uncertainty** — Does the answer avoid inventing information and communicate uncertainty appropriately?
